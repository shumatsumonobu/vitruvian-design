# The artwork fetcher

A tested script that brings one picture, or a few, into a product: a generated image where an image
key is in the environment, a Wikimedia Commons photograph otherwise. A session following the skill
runs it when the declaration's artwork entry asks for a picture; it does not write a fetcher of its
own, and it does not take pictures from stock-photo sites.

## Running it

From the product's root, with Node 22 or later and a network:

```
node <skill>/images/fetch.mjs --subject "<what the picture shows>" --style "<how it is treated>" --name <slug> [--out <dir>] [--size <w>x<h>] [--source auto|generate|photo] [--count N]
```

- `<skill>` is the directory of this skill, `design-discipline/` beside the entry commands.
- `--out` defaults to `assets/` under the current directory.
- `--size` defaults to `1280x720`. A photograph is the closest aspect ratio to it, at least as wide
  where one exists. A generated image is the nearest size the provider offers.
- `--source` defaults to `auto`. `--count` defaults to 1 (at most 10).

## Source order

1. A key in the environment, checked in this order: `GEMINI_API_KEY`, `OPENAI_API_KEY`,
   `TOGETHER_API_KEY` → the picture is generated by that provider.
2. No key, or the generation did not work → a Commons photograph.
3. Neither works → `not taken`. The screen goes without the picture, and the artwork entry says why.

The first printed line says which path was taken and why. A key's value is never printed.
`--source generate` and `--source photo` take one path only and do not fall back.

Generation costs money per image, billed by the provider to the key's owner. Photographs cost
nothing. A session that finds a key in the environment generates, so a person who does not want that
spend leaves the key out of the environment or asks for `--source photo`.

## What it writes and prints

For each image, `<out>/<name>.<ext>` and `<out>/<name>.json` (with `--count` above 1,
`<name>-1.<ext>`, `<name>-1.json`, and so on). The json holds:

- Generated: `source` (`generated`), `provider`, `model`, `prompt` (the text sent: subject, style,
  and a fixed tail asking for no text, no watermark, no logos), `size`, `pricePerImage` (a number
  only where the provider's documentation states one; `null` for all three now, since they bill
  by token or do not state it on the pages read), `credit`.
- Photograph: `source` (`photograph`), `page` (the Commons file page), `author` (HTML stripped),
  `license`, `licenseUrl`, `originalWidth`, `originalHeight`, `credit`.

`credit` is one line the screen shows beside the picture: `Photo: <author>, <license>, Wikimedia
Commons` or `Image generated with <model>`.

One line per image:

```
C:\product\assets\hero.jpg | Photo: Jane, CC BY-SA 4.0, Wikimedia Commons
not taken | search: 5 Commons files for "morning stretch", none with an open license, a bitmap type and at least 640 px width
```

`not taken` names the step (`search`, `metadata`, `download`, `generation`) and what stopped it, and
the exit code is 1. The session reports it as not taken, with that step named.

## Providers

| Key | Call | Default model |
|---|---|---|
| `GEMINI_API_KEY` | `POST generativelanguage.googleapis.com/v1beta/interactions` | `gemini-nano-banana-2.1` |
| `OPENAI_API_KEY` | `POST api.openai.com/v1/images/generations` | `gpt-image-1.5` |
| `TOGETHER_API_KEY` | `POST api.together.ai/v1/images/generations` | `black-forest-labs/FLUX.1-schnell` |

`IMAGES_MODEL_GEMINI`, `IMAGES_MODEL_OPENAI`, `IMAGES_MODEL_TOGETHER` in the environment replace a
model, for the day a provider retires one. Request shapes are in comments above each call in
`fetch.mjs`, with the documentation page each was read from.

## Licenses kept

Photographs only with a license of CC0, public domain, CC BY, or CC BY-SA, any version, and only
bitmaps (jpeg, png, webp). Files narrower than half the target width are skipped. Anything else
(All rights reserved, non-commercial, no-derivatives) is dropped. The screen shows `credit`, which
satisfies the attribution these licenses ask for.

## Time limits

Every network step has a limit; a step past it is `not taken`, naming the step.

| Wait | Limit |
|---|---|
| The Commons search | 15 s |
| The Commons file information | 15 s |
| One image download | 60 s |
| One generation request | 120 s |

On HTTP 429 or 503 the request is made once more, after the delay the server names in
`Retry-After` (1 s where it names none), at most 10 s. A second refusal is `not taken`.

The tests shorten a limit through `IMAGES_LIMITS_MS`, a JSON object: `IMAGES_LIMITS_MS='{"search":300}'`.

## Tests

`node scripts/check-images.mjs` from the repo root runs the fetcher against a stubbed `fetch`, with no
network. `node scripts/check-images.mjs --live` makes one real Commons search for "morning stretch"
into a temporary directory under `scripts/.tmp/` and deletes the files.
