# あさのび デザインの決めごと

あさのび（在宅勤務の人向けの、朝 10 分のストレッチ案内）の見た目の決めごと。画面を作る・直すときは、人もエージェントもこのファイルの値に合わせる。値を変えたいときはこのファイルを書き換える

- 作成: 2026-11-04、design-discipline の `init`
- 合意: README の「デザインの値は init が出したものでよく、置き場は `.design/` でよい」による事前合意
- 根拠の資料（参照したサイトと撮影）: `.design/record.md`
- 見出しの英語名はエントリ名。後のセッションがこの名前で照合するので変えない

## visual concept（見た目の発想元）

昭和のラジオ体操の参加票 — 白いカード紙に藍一色で刷った升目と文字、そこへ毎朝押す朱のはんこ。発想元は [郵政博物館「博物館ノート ラジオ体操」](https://www.postalmuseum.jp/column/collection/radio-exercises.html) の所蔵品の参加票と、昭和4年のポスター「国民保健体操」（大きな朱の円ひとつと、腕を伸ばす人）。朝の体操を毎日つけるカードは、在宅で一人でやる朝のストレッチにも「きょうもやった」を残す形としてそのまま通じる。ストレッチの分野のアプリ（暗い地に光る円のタイマー、連続日数の数字）からは見た目を借りない

## signature（覚えてもらう一点）

今週の参加票。月から日までの 7 つの升目が藍の罫で並び、ストレッチを終えた日の升目に朱の丸いはんこが押されている

- 出る場所: 表紙の「はじめる」のすぐ下。確かめる大きさ（`.design/structure.md`）のどちらでも、送らずに最初に見える範囲に参加票の升目の下端まで入れる。案内の画面ができたら、その最後の画面で、その日の升目にはんこが押される（2026-11-04 の `fix` の I04 で、「あなたの記録」の位置から書き換えた。その位置では 360 × 548 でも 1920 × 900 でも最初に見える範囲の外だった）
- 大胆さはここだけに使う。まわりは白い紙と藍の文字だけで静かにする
- はんこの描き方は `.design/style-system.md`（朱の円の縁と「済」一字、32px）

## colors（色）

| 名前 | 値 | 役目 | 理由 |
|---|---|---|---|
| ai（藍） | `#1F3461` | 文字、見出し、カードの縁の刷り | 参加票は藍一色で刷られている（郵政博物館の撮影）。白地で 12.19:1 |
| shu（朱） | `#C23A22` | accent。押してほしい操作（はじめる）、選択中の状態、進み具合（はんこ） | 参加票に押す朱肉のはんこ、昭和4年ポスターの朱の円。白文字を載せて 5.35:1 |

| daishi（台紙） | `#EEF2F7` | ページの地 | 参加票の外周の淡い青の帯。かんぽ生命のラジオ体操ページにある、ロゴの青を「爽やかな朝の空」とする説明とも合う |

## typefaces（書体）

一つ。[BIZ UDPGothic](https://fonts.google.com/specimen/BIZ+UDPGothic)（ウエイト 400 と 700）を、見出しも本文も数字もすべてに使う

- 理由: 参加票やラジオ体操カードの文字は太めのゴシックの刷り。BIZ UDPGothic は役所の書式や教科書に使われる UD 新ゴの系統で、起きたばかりの人が腕の長さで読んでも字形を取り違えにくい。参照した [富山スガキ「ラジオ体操カードの歴史」](https://www.sugaki.co.jp/radio/) のページも UD 新ゴで組まれていた
- 読み込み: Google Fonts から `display=swap` で読み込む
- 読み込むまでの代わり: `"Hiragino Sans", "Yu Gothic", "Meiryo", sans-serif`（端末に入っているゴシック）
- 強調は 700 のウエイトだけで行う。別の書体に切り替えて目立たせない

## type scale（文字の大きさの段）

body は 1rem（16px）。どの段も BIZ UDPGothic

| 段 | 大きさ | weight | letter-spacing | line-height | 使う所 |
|---|---|---|---|---|---|
| display | 2.5rem（body の 2.5 倍）。幅 600px 未満では 2rem（2 倍） | 700 | 0.04em | 1.4 | 表紙の見出し。一画面に一度だけ |
| title | 1.25rem | 700 | 0.12em | 1.5 | 区切りの見出し（きょうのメニュー）、使い方のシートの題 |
| item | 1.125rem | 700 | 0.04em | 1.5 | メニューのポーズ名、記録の回数と分 |
| lead | 1.125rem | 400 | 0.04em | 1.8 | 見出しの下の説明、記録が無いときの文 |
| body | 1rem | 400 | 0.04em | 1.8 | 本文、使い方のシート |
| label | 1rem | 700 | 0.08em | 1.5 | ボタン、ロゴ |
| small | 0.9375rem（15px） | 400 | 0.04em | 1.7 | 秒数、ほぐす所、道具、参加票の曜日、記録の紙の題（週の見出し） |

- display の跳び: 昭和4年ポスターでは題字が紙の幅いっぱいに大きく、ほかの文字は小さい。表紙で誘う文はひとつだけなので 2.5 倍と大きく跳ばす。幅 600px 未満で 2 倍にするのは、17 字の見出しが 390px 幅で 2 行に収まるようにするため
- title の字間 0.12em: 郵政博物館の参加票の見出し「ラジオ体操の会 参加票」が字間を広く空けて刷られている
- 一番小さい small を 15px にした理由: 秒数と「ほぐす所」は、スマートフォンを腕の長さ（およそ 35cm）に持って、マットやタオルの用意を決めるために読む。14px と 15px で迷ったので大きいほうを取った。色は ai-70
- figures（数字の幅）: BIZ UDPGothic は等幅の数字を持たない（2026-11-04 に確認。`font-variant-numeric: tabular-nums` を指定しても 40px で「1111」100.8px、「0000」121.6px のまま）。秒数を縦に並べる列は右揃えにする
- width: 幅の軸を持たない書体なので指定なし

## maximum line length（一行の最大長）

36em（全角でおよそ 36 字）。見出し下の説明と使い方のシートの本文に効く。日本語の本文 16px で、ノート PC の画面を腕の長さで読むときに行の戻りを見失わない長さ

## maximum content width（中身の最大幅）

40rem（640px）。表紙は参加票一枚ぶんの縦長の紙として組む。ノート PC の 1280px 幅でも、机に置いたカードのように中央に一枚で立てる

## base spacing unit（余白の単位）

8px。余白・間隔はすべて 8 の倍数（8 / 16 / 24 / 32 / 48 / 64）。参加票の升目を 48px（6 単位）とし、はんこ 32px の周りに 8px ずつ空く

- 幅が足りないとき（7 列ぶんの 336px が紙の内側に入らないとき）は、7 列を一行のまま等分に縮める。360px 幅の画面で 1 列約 40px。はんこ 32px は縮めず升の中央に置く。一週間を一行で読める形が参加票なので、二行に折らない（2026-11-04 の `fix` で書き足した）

## radius scale（角丸の段）

| 段 | 値 |
|---|---|
| none | 0 |
| card | 8px |
| pill | 9999px |
| circle | 50% |

ボタンは pill。カード（メニューと記録の紙、使い方のシートの上の角）は card の 8px で、断裁した紙の角くらいにとどめる。参加票の升目は none で、刷った罫どうしが直角で交わる。はんこは circle

## elevation scale（重なりの段）

| 段 | 値 | 意味 |
|---|---|---|
| flat | 影なし。縁に 1px の ai-rule | 机に置いた紙。ページの上のカードはすべてこれ |
| overlay | `0 -8px 32px rgba(31, 52, 97, 0.20)`、下の幕は `rgba(31, 52, 97, 0.48)` | 画面を覆う使い方のシート |

紙は机の上に平らに置かれているので、浮かせるのは画面を覆うものだけにする

## ease-out curve（時間で動く動きの曲線）

`cubic-bezier(0.2, 0.9, 0.3, 1)`。押したときの返事は 120ms、使い方のシートの入りは 280ms、出は 200ms

はんこを押す手の動き — 速く降りて、紙で跳ね返らずに止まる

- 入り 280ms・出 200ms にした理由: 出は入りの道を戻るだけで読む中身が無いので、入りの約 0.7 倍にする。シートは時々開くものなので、出も入りも 200〜300ms の帯に入れる。両方を満たすには入りが 286ms 前後必要で、入り 280ms・出 200ms（0.71 倍）にした（2026-11-04 の `fix` で、入り 240ms・出 240ms から直した。いったん出を 170ms にしたが帯の下限を割ったので直し直した）
- 動きを減らす設定では、シートは大きさと位置を変えずに透明度だけで出入りする

## formats（数と日付の書き方）

- 数: 半角の算用数字。3 桁ごとにカンマ（`toLocaleString("ja-JP")`）。万や k への省略はしない（回数も分も、省略が要る桁に届かない）。小数を出さないので末尾の 0 の扱いは無い。金額は扱わない
- 単位: 数字と単位の間に空白を入れない（10分、30秒、3回）。参加票やポスターの刷りも詰めて組む
- 日付: 日本語の表記で「11月4日（火）」。時刻は 24 時間制。週は月曜はじまり（在宅勤務の週が月曜から始まる）
- 曜日の升目: 月 火 水 木 金 土 日 の漢字一字
- 週の範囲: 「11月2日～11月8日」。両端を `Intl.DateTimeFormat("ja-JP", { month: "long", day: "numeric" })` で整形し、一つの文字列の差し込み口に入れる。参加票の上に「今週（11月2日～11月8日）」として出し、どの週の升目かを示す（2026-11-04 の `fix` で書き足した。`formatRange` は Chrome でも「11/02～11/08」と数字だけになったので使わない）

## voice（話し方）

体操の先生のかけ声のように、短い動詞でやさしく言い切る。ふつうの話し言葉からほとんど離れない。ひらがなは多めにするが、子ども向けの言葉にはしない

## recorded exceptions（意図して使う既定外）

- 中黒「・」で名詞を並べる: 「ほぐす所」と「道具」の行で、肩・首・背中・腰のように名詞を並べるときに使う。日本語で名詞を並べるときの標準の約物で、飾りの区切りではないため。読み上げで間が空くよう、読み上げ用には読点を添える
