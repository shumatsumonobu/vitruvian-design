# あさのび 言葉の目録

あさのびの画面に出る文字列の一覧。一つの意図に一つの言い方だけを使うために、操作の名前、見出し、状態の文がどこに出るかをここで管理する。文字列を足す・変えるときは、人もエージェントも先にここを見て、同じ意図の言い方がすでにあればそれを使う

- 作成: 2026-11-04、design-discipline の `fix`（修繕 R25）
- 話し方は `.design/declaration.md` の voice（体操の先生のかけ声のように、短い動詞でやさしく言い切る）

## audience（誰に向けて書くか）

在宅勤務の人。朝起きてすぐ、半分はスマートフォン、半分はノート PC で開く。ストレッチやヨガの用語に慣れているとは限らない

## 操作の言い方

| 意図 | 言い方 | 出る所 |
|---|---|---|
| 表紙を開き直す | あさのび | 上の帯のロゴ（リンク） |
| 使い方を開く | 使い方 | 上の帯のボタン |
| 使い方を閉じる | 閉じる | 使い方のシートのボタン |
| ストレッチを始める（案内の画面ができるまでは、きょうのメニューへ移る） | はじめる | 誘いの主のボタン、使い方の本文の中（記録の紙の副のボタンは 2026-11-04 の `fix` の I03 で外した） |

## 見出しと題

| 役目 | 言い方 | 出る所 |
|---|---|---|
| 画面の題（タブ） | あさのび — 朝10分のストレッチ | `<title>` |
| 誘いの見出し | からだをのばして、きょうをはじめる | 表紙の見出し |
| 区切りの見出し | きょうのメニュー | 表紙 |
| 週の見出し | 今週（{月曜の日付}～{日曜の日付}） | 記録の紙の題。日付は「11月2日」の形に整形する（「あなたの記録」の区切りの見出しは I03 で外し、この週の見出しを紙の題にした） |
| シートの題 | 使い方 | 使い方のシート |

## 説明と状態の文

| 役目 | 言い方 | 出る所 |
|---|---|---|
| 誘いの説明 | 在宅の朝に、10分。ポーズを1つずつ、残りの秒数を数えながら案内します。 | 表紙の見出しの下 |
| メニューの補足 | ほぐす所 肩・首・背中・腰 | メニューの紙の下 |
| メニューの補足 | 道具 ヨガマット・タオル | メニューの紙の下 |
| 秒数 | {秒}秒 | メニューの行の右 |
| 記録あり | これまで{回}回、合計{分}分 | 記録の紙の一行 |
| 空 | 今週はまだはんこがありません。 | 記録の紙の一行。その下に「記録あり」の一行が続く |
| はじめて | まだ記録はありません。ストレッチを終えた日の升目に、はんこが押されます。 | 記録の紙の一行 |
| 読めない（保存が止められている） | 記録を読み込めませんでした。ブラウザでこのサイトのデータ保存が止められていると、記録を読めません。設定で許可して、ページを読み込み直すと出ます。 | 記録の紙の一行 |
| 読めない（保存された記録の形が壊れている） | 記録を読み込めませんでした。この端末に保存された記録の形が正しくありません。ブラウザの設定でこのサイトのデータを消すと、記録をはじめから付けられます。 | 記録の紙の一行（2026-11-04 の `fix` の I08 で足した） |
| 曜日の升 | 月、火、水、木、金、土、日 | 参加票の上の段（読み上げからは隠し、各列の読み上げの句に含める） |
| 参加票の升（読み上げだけ） | {曜日}曜日 はんこあり / {曜日}曜日 はんこなし | 参加票の各列 |
| 参加票の名前（読み上げだけ） | 今週の参加票 | 参加票の一覧 |
| はんこの字 | 済 | 押した日の升の印影（読み上げからは隠す） |
| 使い方の本文 | 「はじめる」を押すと、きょうのメニューまで進みます。案内の画面はこれから作ります。 | 使い方のシート |

- {秒}・{回}・{分} は `toLocaleString("ja-JP")` で整形した数。数と単位の間に空白を入れない
- 文は文字列一つに差し込み口を置いて作る。断片をつないで文にしない

## 使わない言葉（日本語での当てはめ）

| 種類 | 使わない言葉 |
|---|---|
| 詫び・あいまいな失敗 | 申し訳ありません、すみません、エラーが発生しました、問題が発生しました、おっと |
| つなぎ言葉（just、simply、easily、please、actually） | 〜だけ、ただ〜、かんたんに、手軽に、〜してください、どうぞ、実は |
| ほめ言葉 | パワフル、シームレス、手間いらず、革新的、魔法のような、爆速、次世代 |
| 数の代わりの言葉 | たくさんの、数千の、無数の |

## 用語

| 用語 | 扱い |
|---|---|
| キャット・カウ、ダウンドッグ、チャイルドポーズ | audience の語彙に無いヨガの名前。一行の説明が要るが、説明の文は README にもデータにも無い。`.design/record.md` に人に決めてもらうこととして書いた |
| 参加票、はんこ | ラジオ体操のカードとして audience に通じる語。そのまま使う |
