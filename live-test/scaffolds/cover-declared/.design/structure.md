# あさのび 画面の組み立て

design-discipline の rules/layout.md が求める、面ごとの組み立てと、確かめる寸法。

## 確かめる寸法

| 寸法 | 理由 |
|---|---|
| 1536×700 | いちばん広い幅。ノート PC の 1920×1080 を、OS が 125% に拡大し、ブラウザのタブとアドレス欄が残した高さ |
| 360×560 | いちばん狭い幅。よくあるスマートフォンの幅で、ブラウザの上下の欄が出ている高さ |

## 表紙

- 流れ: 1 列。上から ヘッダー → はじめる → きょうのメニュー → あなたの記録 → フッター
- 幅を止めるもの: 中身の最大幅 40rem。本文は 36em で折り返す
- 並びの理由: 説明の「表紙には、きょうのメニューと、これまでの記録が出る。「はじめる」を押すとメニューまで進む」の順

## 使い方シート

- 画面の下から出る面。上辺だけ角丸 large、影は overlay、後ろに幕
